🧠 Python Interview Concepts (The Must-Knows)

Architectural Differences

# 1. Mutable vs Immutable
# Mutable (Can change): Lists, Dicts, Sets
# Immutable (Cannot change, must recreate): Strings, Tuples, Ints
a = (1, 2)
# a[0] = 5  <-- TypeError: 'tuple' does not support item assignment

# 2. List vs Set
# Lists: O(N) lookup. Allows duplicates.
# Sets: O(1) instant lookup (Hash Table). Unique only.

# 3. == vs is
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b) # True (Values match)
print(a is b) # False (Different memory addresses)

# 4. Shallow vs Deep Copy
import copy
deep_copy_list = copy.deepcopy(original_list) # Entirely independent objects

5. Loops & Iteration

Advanced Iteration (Enumerate & Zip)

Stop using range(len()). Use these instead.

# 1. Enumerate: Get Index and Value simultaneously
names = ['Alice', 'Bob']
for idx, name in enumerate(names):
    print(f"{idx}: {name}")

# 2. Zip: Iterate two lists in parallel
ages = [25, 30]
for n, a in zip(names, ages):
    print(f"{n} is {a}")

6. Lists & Tuples

List Methods & Slicing

l = [10, 20, 30]
l.append(40)       # Adds to end
l.insert(0, 5)     # Insert 5 at index 0
last = l.pop()     # Removes & returns last item

# Slicing: list[start:stop:step]
first_two = l[0:2]
reversed_l = l[::-1] # Powerful trick to reverse

List Comprehension ⭐

Creates lists instantly in C-optimized speed.

# Syntax: [expression for item in iterable if condition]
squares = [x*x for x in range(5)]
evens = [x for x in squares if x % 2 == 0]

# Tuple Unpacking
coords = (40.7, -74.0)
lat, lon = coords # Unpacks instantly

11. Functions & Advanced Scope

*args & **kwargs

def magic(*args, **kwargs):
    # args is a Tuple of positional arguments
    print(sum(args)) 
    
    # kwargs is a Dict of keyword arguments
    for k, v in kwargs.items():
        print(k, v)

magic(1, 2, 3, name="John", age=30)

Lambdas & Map/Filter

# Lambda: Anonymous, 1-line functions
add = lambda x, y: x + y

# Map: Apply function to all
nums = [1, 2, 3]
doubled = list(map(lambda x: x*2, nums))

# Filter: Keep only items where True
evens = list(filter(lambda x: x%2==0, nums))

12. Files & Exception Handling

Safe File I/O (Context Manager)

# 'with' auto-closes the file even if error occurs
with open('data.txt', 'w') as f:
    f.write("Hello File\n")

with open('data.txt', 'r') as f:
    lines = f.readlines() # Returns list of strings

Full Try/Except Block

try:
    x = 10 / 0
except ZeroDivisionError as e:
    print("Math Error:", e)
except Exception as e:
    print("Catch-all fallback")
else:
    print("Runs ONLY if no errors occurred")
finally:
    print("Always runs (good for cleanup)")

15. Object-Oriented Programming (OOP)

Classes, Inheritance, and Super()

class Animal:
    def __init__(self, name):
        self.name = name  # Instance variable
    
    def speak(self):
        raise NotImplementedError("Subclass must implement")

# Inheritance
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name) # Calls Parent's __init__
        self.breed = breed
        
    # Polymorphism (Overriding parent method)
    def speak(self):
        return f"{self.name} says Woof!"

d = Dog("Rex", "German Shepherd")
print(d.speak())
