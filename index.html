🐍 The Ultimate Python Cheat Sheet

🧠 Interview & Architectural Concepts ⭐

Mutable vs Immutable: Lists/Dicts/Sets can be changed. Tuples/Strings/Ints cannot.

List vs Tuple: Lists `[]` are mutable & slower. Tuples `()` are immutable & faster.

List vs Set: Lists allow duplicates & O(N) search. Sets `{}` are unique & O(1) instant search.

== vs is: `==` checks if VALUES match. `is` checks if MEMORY ADDRESS match.
Shallow vs Deep Copy: Shallow copy copies references. Deep copy creates entire new independent objects in memory.

*args vs **kwargs: `*args` unpacks positional into Tuple. `**kwargs` unpacks keyword into Dict.

Garbage Collection: Python automatically deletes objects from memory when their reference count hits zero.

1. 🟢 Basics & Data Types

  • print(x) Output
  • x = input() Input (Returns Str)
  • type(x) Get Data Type
  • int(), str(), float() Type Casting
  • f"Hi {name}" f-String Formatting
  • True / False / None Booleans & Null

3. ➕ Operators & Logic

  • +, -, *, /, % Arithmetic (Modulo)
  • ==, !=, >, < Comparison
  • and, or, not Logical
  • in, not in Membership Test
  • if x > 0: ... elif: ... else: Conditionals
  • x if condition else y Ternary Operator

5. 🔁 Loops

  • for i in range(5): 0 to 4
  • while x > 0: Loop until False
  • break Destroy Loop
  • continue Skip to Next
  • for idx, val in enumerate(L): Loop with Index
  • for a, b in zip(L1, L2): Loop multiple lists

6. 📦 Lists []

  • L.append(x) Add to end
  • L.pop() Remove & Return last
  • L.remove(x) Remove specific value
  • L[start:stop:step] Slicing
  • [x*2 for x in L] List Comprehension ⭐
  • L.sort() In-place sort

8. 📖 Dictionaries {}

  • d = {'k': 'v'} Create
  • d['k'] = 'v2' Add / Update
  • d.get('k', default) Safe Access
  • d.keys(), d.values() Iterable views
  • d.items() Iterate (key, value)
  • {k: v for k,v in L} Dict Comprehension ⭐

9. 🧩 Sets {}

  • s = {1, 2, 3} Create
  • s.add(x) Add item
  • s.discard(x) Safe remove
  • s1 | s2 Union
  • s1 & s2 Intersection
  • s1 - s2 Difference

10. 🔤 Strings

  • s.upper() / s.lower() Case change
  • s.strip() Remove whitespace
  • s.replace(old, new) Find & Replace
  • s.split(',') String to List
  • ','.join(List) List to String
  • s.startswith('A') Check prefix

11. ⚙️ Functions & Functional

  • def my_func(a, b=5): Definition
  • return x Output
  • lambda x: x*2 Inline Function ⭐
  • list(map(func, L)) Apply func to all
  • list(filter(func, L)) Keep if True
  • def f(*args, **kwargs): Dynamic Args

12. 📁 Files & 🚨 Exceptions

  • with open('x.txt', 'r') as f: Safe File Open
  • f.read() / f.write() I/O
  • try: ... except Exception: Catch Errors
  • finally: Always runs
  • raise ValueError() Trigger custom error

15. 🏗️ Object-Oriented (OOP)

  • class Dog: Blueprint
  • def __init__(self): Constructor
  • self.name = 'x' Instance Variable
  • class Poodle(Dog): Inheritance
  • super().__init__() Call Parent
