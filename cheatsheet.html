🛠️ The UMPIRE Problem Solving Framework

Your strategic cheat-code for conquering any complex algorithmic interview question.

1. Understand

Ask clarifying questions. Identify inputs/outputs. Determine edge cases and constraints.

2. Match

Match the problem to known patterns (e.g., Hash Map, Two Pointer, Sliding Window, DFS).

3. Plan

Write out the algorithm steps in plain English pseudo-code before writing any Python.

4. Implement

Translate your plan into actual Python code. Keep it clean and modular.

5. Review

Trace your code manually line-by-line with a simple test case to catch logical bugs.

6. Evaluate

Analyze Time (Speed) and Space (Memory) Complexity using Big O Notation.

6. 📦 Lists (Mutable, O(N))

  • l = [1, 2, 3] Create
  • l[0] / l[-1] Index / Last
  • l[start:stop:step] Slicing
  • l.append(4) Add one to end
  • l.extend([5,6]) Merge lists
  • l.insert(0, 9) Add at index
  • l.remove(9) Remove by value
  • l.pop() Remove/Return last
  • l.sort() In-place sort
  • l.reverse() In-place reverse
  • l.count(1) Count occurrences
  • l.index(2) Find first index
# List Comprehension ⭐ (C-Speed)
sq = [x*x for x in nums if x>0]

7. 📌 Tuples (Immutable, Fast)

  • t = (1, 2, 3) Create
  • a, b, c = t Unpacking
  • t.count(1) Count occurrences
  • t.index(2) Find first index
# ⭐ Tuple vs List
# Tuples are read-only (immutable), which
# makes them highly memory efficient and
# slightly faster for iteration than lists.

8. 📖 Dictionaries (Hash Map)

  • d = {'a': 1} Create
  • d['b'] = 2 Add / Update
  • del d['a'] Delete key
  • d.keys() Iterate keys
  • d.values() Iterate values
  • d.items() Iterate (k, v)
  • d.get('a', 0) Safe access
  • d.update(d2) Merge dicts
  • d.pop('a') Remove & Return
# Dict Comprehension ⭐
sq = {x: x*x for x in range(5)}

9. 🧩 Sets (Unique, O(1))

  • s = {1, 2} Create
  • s.add(3) Add
  • s.remove(1) Errors if missing
  • s.discard(1) Safe remove
  • s1 | s2 Union (Merge)
  • s1 & s2 Intersection (Both)
  • s1 - s2 Difference
  • s1 ^ s2 Symmetric Diff

10. 🔤 Strings (Immutable)

  • s[0:3] Slicing
  • s.upper() / lower() Case
  • s.strip() Remove space
  • s.replace('a','b') Find & Replace
  • s.split(',') String to List
  • ','.join(lst) List to String
  • s.find('x') Returns index / -1
  • s.startswith('a') Bool check
  • s.endswith('z') Bool check
  • s.count('x') Count chars

12. 📁 File Handling

    text = f.read()      # Whole file

13. 🚨 Exception Handling

try:
    x = 1 / 0
except ZeroDivisionError as e:
    print("Math err:", e)
except Exception:
    print("Catch all")
else:
    print("Runs if NO errors occurred")
finally:
    print("Always runs (cleanup)")

# Raise custom error
raise ValueError("Bad input")

15. 🏗️ OOP (Classes)

class Animal:
    def __init__(self, name):
        # Instance variable (Encapsulation)
        self.name = name
        
    # Method / Abstraction
    def speak(self):
        pass

# Inheritance
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed
        
    # Polymorphism (Override)
    def speak(self):
        return "Woof"

🧠 16. Interview Concepts ⭐

Mutable vs Immutable: Lists/Dicts/Sets change in place. Tuples/Strings recreate in memory.

== vs is: `==` checks Values. `is` checks Memory Address.

Shallow vs Deep Copy: `copy()` copies outer container references. `deepcopy()` creates fully independent clones.

Iterator vs Iterable: Iterable is the container (List). Iterator is the machine looping over it (`__next__`).

Generators & yield: Functions that pause execution and return items one at a time via `yield`. Highly memory efficient for massive datasets.

Decorators: Functions that wrap other functions to modify behavior without changing source code (e.g., `@login_required`).

Garbage Collection: Python auto-deletes memory when reference count hits 0.

PEP 8: The official Python styling guide (snake_case, 4 spaces).
