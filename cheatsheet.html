🛠️ The UMPIRE Problem Solving Framework

1. Understand

Ask clarifying questions. Identify inputs/outputs. Determine edge cases.

2. Match

Match problem to known patterns (Hash Map, Two Pointer, Sliding Window).

3. Plan

Write out the algorithm steps in plain English pseudo-code.

4. Implement

Translate your plan into actual Python code. Keep it clean.

5. Review

Trace your code manually line-by-line with a simple test case.

6. Evaluate

Analyze Time and Space Complexity (Big O Notation).

6. 📦 Lists (Mutable, O(N))

  • l = [1, 2, 3] Create
  • l[0] / l[-1] Index / Last
  • l[start:stop:step] Slicing
  • l.append(4) Add one to end
  • l.extend([5,6]) Merge lists
  • l.insert(0, 9) Add at index
  • l.remove(9) Remove by value
  • l.pop() Remove/Return last
  • l.sort() In-place sort
  • l.reverse() In-place reverse
  • l.count(1) Count occurrences
  • l.index(2) Find first index
# List Comprehension ⭐
sq = [x*x for x in nums if x>0]

  • t = (1, 2, 3) Create
  • a, b, c = t Unpacking
  • t.count(1) Count occurrences
  • t.index(2) Find first index

8. 📖 Dictionaries (Hash Map)

🧠 16. Interview Concepts ⭐

Mutable vs Immutable: Lists/Dicts/Sets change in place. Tuples/Strings recreate in memory.

== vs is: `==` checks Values. `is` checks Memory Address.

Shallow vs Deep Copy: `copy()` copies outer container references. `deepcopy()` creates fully independent clones.

Iterator vs Iterable: Iterable is the container (List). Iterator is the machine looping over it (`__next__`).

Generators & yield: Functions that pause execution and return items one at a time via `yield`. Highly memory efficient for massive datasets.

Decorators: Functions that wrap other functions to modify behavior without changing source code (e.g., `@login_required`).

Garbage Collection: Python auto-deletes memory when reference count hits 0.

PEP 8: The official Python styling guide (snake_case, 4 spaces).
